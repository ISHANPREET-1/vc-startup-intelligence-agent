# VC Startup Intelligence Agent

An AI-powered startup discovery and ranking workflow built with n8n.

## Features

- Discovers startups from online sources
- Extracts funding and company information using AI
- Aggregates startup data
- Ranks startups based on investment potential
- Multi-agent architecture

## Tech Stack

- n8n
- OpenRouter
- Google Search API
- AI Agents

## Repository Contents

- workflow.json (n8n workflow export)

Built as an exploration of AI-powered startup intelligence and workflow automation.
